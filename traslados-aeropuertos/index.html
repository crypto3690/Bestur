Lo importante no es solo llegar

Monitoreo de vuelo

Para llegadas tomamos como referencia la hora oficial de la aerolínea y revisamos cambios del vuelo.

Equipaje considerado

La recomendación de vehículo para aeropuertos considera pasajeros y equipaje, no únicamente el número de asientos.

Horario con margen

Para salidas calculamos una referencia conservadora para reducir el riesgo de llegar con el tiempo justo.

Confirmación formal

El servicio queda totalmente confirmado cuando BESTUR envía la confirmación con folio y datos definitivos.

Preguntas frecuentes

Antes de viajar al aeropuerto

¿BESTUR monitorea mi vuelo?

Sí. Para llegadas tomamos como referencia la hora oficial publicada por la aerolínea y monitoreamos cambios para ajustar la recepción cuando el vuelo se adelanta o retrasa.

¿Con cuánto tiempo debo salir de San Miguel de Allende?

Como referencia operativa, recomendamos salir 3 horas y 30 minutos antes de la hora del vuelo para BJX y QRO, y 7 horas antes para AICM y AIFA.

¿Qué vehículo se utiliza?

Para traslados de aeropuerto consideramos pasajeros y equipaje: Sedán para 1–2 pasajeros, Suburban para 3–6, Hiace/Transit para 7–10 y Crafter para 11–16. Grupos mayores requieren cotización especial.

¿El precio cambia si pago con tarjeta o necesito factura?

La referencia de efectivo o transferencia corresponde a la tarifa directa. Para tarjeta o factura se agrega 16% de IVA.

¿Cuándo queda confirmado mi traslado?

La solicitud o cotización no confirma automáticamente el servicio. El traslado queda totalmente confirmado cuando BESTUR envía la confirmación con folio y datos operativos definitivos.
